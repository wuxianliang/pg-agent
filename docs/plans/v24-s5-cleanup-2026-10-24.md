## 4. 冻结合同 C24–C27

### C24 cleanup 顺序（合并 DAG）

**节点与边**（全部来自十表现有列，不新增结构）：

- owner 边：`child_install.owner_fiber_id → fibers.fiber_id → fibers.install_id = owner_install`，并校验 `child_install.owner_episode_id` 是该 fiber 的不可变 episode（`episodes(fiber_id,episode_id)`）。遍历键**只**用 `(owner_fiber_id, owner_episode_id)`，**不**联接 `fibers.current_episode_id`（设计 §6.6）。
- scope 闭包：owner 边可能跨 scope（当前 admission 不要求 child install 与 owner fiber 同 scope，40:1860-1880 只校验 owner 活性）。因此 `cleanup_graph(scope)` 的种子是「本 scope 的 install ∪ 它们的 owner 后代 ∪ 后代 install 的 dependency 邻居」，`scope_closable` 对本 scope 及其 owner 后代一起判定义务；不收紧 admission。记 D-S5-10。
- dependency 边：`consumer_fiber`（activation pin 的 `consumer_episode_id`，或 run pin 的 `consumer_run_id → runs.owner_fiber_id`）→ 该 pin 的 `provider_episode_id → episodes.fiber_id → provider_fiber → provider_install`。边只对 `pins.released_at IS NULL` 存在。
- 贡献序：同一 fiber 内的 `slots` 不是图边，按 `contribution_seq DESC` 逐个撤销（LIFO），一次 advance 至多撤销一条。

**序**（必须同时成立）：

1. child install 先于 owner install 进入 `disposed`；owner 的 `dispose_pending` 在 child 未 disposed 前不得发 `host_release`，也不得写 `disposed`。
2. consumer 先于 provider：provider install 的 slot 不得在引用它的 live pin 清零前 `released`；provider 的 `dispose` 在自身 slots 未全释放前不得发 release。
3. 同一 fiber 的 slot 按 `contribution_seq DESC` 释放；episode 只在全部 slot 释放、pins 清零、child install disposed 后 `closed`。
4. 合并图有环 → `cleanup_cycle`，W1（失败 command receipt，零领域写、零 successor），`detail={path:[uuid…],edge:'owner'|'dependency'}`。**环不在一个 advance 内递归求解**：发现即拒绝，不尝试「绕过环继续清理」。

**有界阶段**：每次 `advance` 只推进一个阶段、总写行 ≤16、发 ≤16 successor；`dispose` 的级联是**迭代工作队列 + 深度优先**（不是递归函数调用），行预算用尽即停并返回 `blocked`。阶段集合固定为 `drain | retire | cascade | release | close | dispose`。不递归调用 `advance`，不用递归 CTE 在一次 advance 内跑完整闭包。进展由单调量保证：每个阶段的成功提交都减少 `v24.cleanup_pending(scope_id)` 的未清义务数；屏障未清时返回 `deferred` 且零写。

**失败不写终态**：任何失败/unknown 路径不得写 `installs.state='disposed'`、`scopes.closed_at`、`episodes.state='closed'`。applier 在 DML 前用 `v24.install_disposed_ok(install_id, p_effect_id)` / `v24.scope_closable()` 重算（不是只信 interpreter 的 delta）。

### C25 inspect 收敛

- `inspect_resource` 是普通外部 effect，`kind` 已在闭集（10:97）。claim 在 `v24.claimable_kinds()` 打开，**与结算注册同一提交**（W2）。
- identity：`v24.inspect_effect_id(p_owner_effect uuid, p_install_id uuid) = md5(p_owner_effect::text || ':inspect_resource:' || p_install_id::text || ':0')::uuid`。`p_owner_effect` 是发出 inspect 的 command effect（`command_dispose`/`command_scope_control`/`command_fiber_control`）。**必须带 install_id**：一条 command 可以级联多个 install，只按 owner effect 派生会撞 id。同一 command 重放得到同一 inspect id；新的 dispose 命令（新 key）得到新 inspect。
- request（冻结键集，claim 前校验）：
  ```json
  {"v":1,"install_id":"<uuid>","target":"host_prepare|host_release",
   "target_effect_id":"<uuid>",
   "reservation":"v24:host_prepare:<hid>|v24:host_release:<rid>",
   "request_digest":"<hex64>"}
  ```
  `reservation` 必须与 `target_effect_id` 的 `v24:host_prepare:`/`v24:host_release:` 命名空间**逐字节一致**；`request_digest` 是该 host effect 的 `request_digest`。inspect 自己的 reservation 是 `v24:inspect_resource:<inspect_effect_id>`（只用于 host journal，不写回 install）。
- outcome：
  - success：`{result:{v:1,observed:'known'|'absent',target_effect_id,reservation}}`；
  - failure：`class=failure`，`result:{v:1,observed:'unknown',reason:'inspect_failed'}`。`inspect_failed` 是 **outcome 的 reason 字符串**，不是 `error_v1` 错误码（见 §5.7）；
  - unknown：`{result:{v:1,observed:'unknown'}}`。
- 收敛矩阵（`class` × `observed`）：

  | target | known | absent | unknown |
  |---|---|---|---|
  | `host_prepare` | `preparing|prepare_unknown→installed`（制品存在，可再次 dispose） | `preparing|prepare_unknown→prepare_failed`（可显式 retry 或 dispose） | 保持原态（`preparing` 或 `prepare_unknown`），不写 `closed_at` |
  | `host_release` | `dispose_pending→disposed`（外部已释放，**不再发第二次 release**） | `dispose_pending` 保持，发新的 `host_release`（新 effect/新 reservation） | 保持 `dispose_pending`，可再次 inspect（新 dispose key） |

- `resource_quiesced_at`：只在**证明静默**时置位。success/failure 的 host 回执维持 S2/S4 现状（40:2651、48:2055）；inspect 的 success（known/absent）额外把**被 inspect 的那条 host effect**置 `resource_quiesced_at=now()`。inspect 自身 failure/unknown 不置位。`unknown` 且 `resource_quiesced_at IS NULL` 的 host effect 一律阻止 `disposed` 与 `closed_at`。
- `dispose_pending` 可恢复：owner 再次 `dispose`（新 request_key）时，先看该 install 是否有 `host_release status='unknown' AND resource_quiesced_at IS NULL`；有则**只发 inspect**，绝不发第二条 release；无则按 §C27 发 release。
- `preparing`/`prepare_unknown` 的 dispose **不进入** `dispose_pending`：先把状态保持在原态；`host_prepare` 仍 `ready|claimed` 时阻塞（不 inspect 未执行的 effect），`unknown` 时发 inspect（target=`host_prepare`）。`known→installed`（可再次 dispose，走正常 release）；`absent→prepare_failed`（可 dispose，且因从未有成功 prepare，直接 disposed、0 条 release）；`unknown` 保持原态。理由：C7 的状态迁移只允许 `preparing→installed|prepare_failed|prepare_unknown` 与 `dispose_pending→disposed`；若先写 `dispose_pending`，inspect 后无法合法转 `installed`。记 D-S5-11。

### C26 scope close

- `close` 只经 `command_scope_control`。同 request_key 重放返回首次 response；对已 `closed_at` 的 scope 用新 key 返回 W1 `already_terminal`（domain 零写 + failed receipt）。
- `close_requested_at` 一旦写入，**立即**拒绝：新 child scope（40:71）、新 install（40:1843）、`start`（40:1681）、`fiber_control(on)`（40:2031）、新 pin（只能由 start/activation 产生）。close 不删除既有事实。
- 推进是**有界 phase 机**，由重复的 `close` 调用（每次新 request_key）驱动；每次调用只做**一个** phase、≤16 行、≤16 successor：
  1. `request`：写 `close_requested_at`（若已写则跳过），发 `scope_close_requested`。
  2. `drain`：≤8 条非 terminal run。无 `ready|claimed|unknown-without-quiesced` 的 model/tool effect → 直接 `status='cancelled', ended_at=now(), close_intent={kind:'cancel'}`, 按 `run_pin_release_set` 释放 run pins，发 `run_cancelled_by_scope_close`；否则只写 `close_intent={kind:'cancel'}`（等 C23 `loop_sealable` 收口）。
  3. `retire`：≤8 条未 disposed fiber。`want_on=false, control_seq=control_seq+1`；episode `active→retiring` + 本代 slots `withdrawn_at=now()`；屏障（pins / child installs / host effects）清零后进入 `release`。
  4. `cascade`：≤8 条 child install（按固定 owner 键）→ `dispose_pending`；义务已清的发 `host_release`，有 unknown-without-quiesced 的发 `inspect_resource`（successor 计入 ≤16 上限）。
  5. `barrier`：child scope 未 `closed_at` → `deferred`；本 scope 及其 owner 后代的 install 未全 `disposed`、fiber 未全 disposed、run 未全 terminal、有未结算 host/inspect effect → `deferred`。
  6. `finalize`：`v24.scope_closable(scope_id)` 为真 → `closed_at=now()`，发 `scope_closed`。
- `closed_at` **只由 close 命令写**。settlement 不写 `closed_at`（避免第二关闭状态机；这与 §10.2-F4 的推荐一致）。
- 子 scope 先于 parent：parent 的 `scope_closable` 要求所有 `parent_id=scope_id` 的 child `closed_at IS NOT NULL`；gate 断言 `child.closed_at < parent.closed_at`。
- phase 可观测性：不新增 response 字段（C2 冻结），phase 与 pending 计数写入 `events`（entity_type=`scope`，event_kind=`scope_close_phase`，payload `{phase,pending:{runs,fibers,installs,children}}`）。`deferred` 沿用现有 disposition。
- 无 inspect 时永久 closing：`prepare_unknown`/`host_release unknown` 未得 `known|absent` 前，`prepare_unknown` 的 install 不得 `disposed`，`scope_closable` 恒 false。

### C27 完整 dispose 闭包

- `dispose(install_id, request_key)` 仍只经 `admit_and_apply(kind=command_dispose)`。解释器调用共享 helper `v24.dispose_stage(install_id, by_effect, mode)`；`mode ∈ command|cascade|close`。**只有这一份语义**，三种入口只改 `mode` 与 receipt 归属。
- **prepare 分支优先**：state 为 `preparing`/`prepare_unknown` 时，`dispose_stage` 只发 inspect（C25），不改 state、不写 `dispose_pending`、不发 release。
- 义务（全部满足才发 `host_release`，全部仍满足才允许 `disposed`）：
  1. 该 install 的所有 fibers `disposed_at IS NOT NULL`；
  2. 这些 fibers 的所有 episodes `state='closed'`；
  3. 这些 fibers 的所有 slots `released_at IS NOT NULL`；
  4. 通过固定 `(owner_fiber_id,owner_episode_id)` 找到的 child installs 全部 `disposed`；
  5. 没有 `ready|claimed` 或 `unknown AND resource_quiesced_at IS NULL` 的 `host_prepare|host_release|inspect_resource` 引用该 install；
  6. 无 `cleanup_cycle`。
- owner 级联：`dispose_stage` 用迭代队列把 child install 依次置 `dispose_pending, dispose_effect=<by_effect>`，并按 `child 先于 owner` 深度优先处理；child 的义务清空后由**同一个** `by_effect` + `install_id` 派生 `md5(by_effect||':host_release:'||install_id||':0')` 发 release（reservation `v24:host_release:<id>`）。已有 `ready|claimed` release 则复用。一次 advance 的行预算 ≤16；预算用尽即返回 `blocked`，下一次 advance 从队列剩余处继续。
- 依赖逆序：provider 的 `dispose_stage` 在自身 slot 未释放前阻塞（slot 释放要求 live pin=0，pin 由 consumer 的 release 清）。G4-C 用 3 节点 consumer→provider 图断言。
- 贡献逆序：`release` 阶段每次只释放 `contribution_seq` 最大的一条未释放 slot；该 slot 的 consumer pins 先释放（`released_by_effect=<by_effect>`），再 `slots.released_at=now()`。全部释放后才 `episode closed` + `current_episode_id=NULL` + fiber `disposed_at`（由 install dispose 写）。
- 墓碑：`host_release` success → `disposed` + `disposed_at=now()` + 一条 `install_disposed`。applier 在 UPDATE 前重算 `v24.install_disposed_ok(install_id, p_effect_id)`（排除正在结算的 release，否则自指为 false）；不满足 → `invalid_outcome` 回滚（不写半墓碑）。
- 重试：
  - `host_release failure`（`resource_quiesced_at` 已置）→ 保持 `dispose_pending`；新 request_key 发**新** release（新 effect id / 新 reservation；failure receipt 证明本次 IO 未产生外部改变）。
  - `host_release unknown` → 保持 `dispose_pending` + 该 effect `resource_quiesced_at IS NULL`；新 key **先 inspect**，按 C25 矩阵收敛，绝不再发 release。
  - `host_release success` 后任何重放：同 key 返回首次 response；新 key `already_terminal`（domain 零写 + failed receipt）。
  - `dispose_pending` 期间收到 `host_prepare` 回执 → `receipt_conflict`（现状 40:2537-2541 保留）。
- **无 prepare 成功的直接墓碑**：若该 install 从未有过成功的 `host_prepare`（状态仅 `prepare_failed`，或 inspect `absent` 后转 `prepare_failed`），外部没有制品引用；进入 `dispose_pending` 后在全义务满足时直接写 `disposed`+`disposed_at`，**不发** `host_release`（0 条 release effect），事件 `install_disposed`（payload `{released:false}`）。G4-J② 断言。
- 失败不写墓碑：release failure/unknown、inspect unknown、child 未清、环，全部不得写 `disposed`/`disposed_at`。

```sql
-- 一条 install 的直接出边：owner 边 + live dependency 边。只读。
CREATE FUNCTION v24.cleanup_edges(p_install_id uuid)
RETURNS TABLE(next_id uuid, edge text)
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  SELECT oi.install_id, 'owner'::text
    FROM v24.installs ci
    JOIN v24.fibers f ON f.fiber_id = ci.owner_fiber_id
                     AND f.install_id <> ci.install_id
    JOIN v24.installs oi ON oi.install_id = f.install_id
   WHERE ci.install_id = p_install_id AND ci.owner_fiber_id IS NOT NULL
  UNION
  SELECT pf.install_id, 'dependency'::text
    FROM v24.fibers cf
    JOIN v24.pins p ON p.released_at IS NULL
     AND (p.consumer_episode_id IN (SELECT e.episode_id FROM v24.episodes e
                                     WHERE e.fiber_id = cf.fiber_id)
          OR p.consumer_run_id IN (SELECT r.run_id FROM v24.runs r
                                    WHERE r.owner_fiber_id = cf.fiber_id))
    JOIN v24.episodes pe ON pe.episode_id = p.provider_episode_id
    JOIN v24.fibers pf ON pf.fiber_id = pe.fiber_id
   WHERE cf.install_id = p_install_id AND pf.install_id <> p_install_id
$$;

-- 合并 DAG 展开。返回同一节点可能多行（不同路径/深度），调用方按 node_id 去重。
CREATE FUNCTION v24.cleanup_graph(p_scope_id uuid)
RETURNS TABLE(node_kind text, node_id uuid, parent_kind text, parent_id uuid,
              edge text, depth int)
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  WITH RECURSIVE g(node_id, parent_id, edge, depth) AS (
    SELECT i.install_id, NULL::uuid, NULL::text, 0
      FROM v24.installs i WHERE i.scope_id = p_scope_id
    UNION ALL
    SELECT e.next_id, g.node_id, e.edge, g.depth + 1
      FROM g CROSS JOIN LATERAL v24.cleanup_edges(g.node_id) e
     WHERE g.depth < 64
  )
  SELECT 'install'::text, g.node_id, 'install'::text, g.parent_id, g.edge, g.depth
    FROM g
   ORDER BY g.depth, g.node_id;
$$;

-- scope 清理闭包：本 scope 的 install 及其 owner 后代（可跨 scope）。
CREATE FUNCTION v24.cleanup_closure(p_scope_id uuid)
RETURNS TABLE(install_id uuid)
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  SELECT DISTINCT g.node_id FROM v24.cleanup_graph(p_scope_id) g
$$;

-- 环检测：返回闭合路径（含重复的终点，如 {A,B,C,A}）；空数组=无环。
-- 深度上限 64；到上限仍无重复时返回错误哨兵 {p_install_id}（fail-closed，按环处理）。
CREATE FUNCTION v24.cleanup_cycle(p_install_id uuid) RETURNS uuid[]
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  WITH RECURSIVE walk(node_id, path) AS (
    SELECT p_install_id, ARRAY[p_install_id]
    UNION ALL
    SELECT e.next_id, w.path || e.next_id
      FROM walk w CROSS JOIN LATERAL v24.cleanup_edges(w.node_id) e
     WHERE cardinality(w.path) <= 64
       AND NOT e.next_id = ANY(w.path)
  )
  SELECT coalesce(
    (SELECT w.path || e.next_id
       FROM walk w CROSS JOIN LATERAL v24.cleanup_edges(w.node_id) e
      WHERE e.next_id = ANY(w.path)
      ORDER BY cardinality(w.path) LIMIT 1),
    CASE WHEN EXISTS (SELECT 1 FROM walk w WHERE cardinality(w.path) > 64)
         THEN ARRAY[p_install_id] ELSE '{}'::uuid[] END)
$$;

-- 未清义务计数（G4-Q 的单调量）：run + install + fiber + child scope + host/inspect effect。
CREATE FUNCTION v24.cleanup_pending(p_scope_id uuid) RETURNS int
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  SELECT
    (SELECT count(*) FROM v24.runs r
      WHERE r.scope_id = p_scope_id AND r.status NOT IN
            ('completed','failed','cancelled','blocked_unknown'))
  + (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
       JOIN v24.installs i ON i.install_id = c.install_id
      WHERE i.state <> 'disposed')
  + (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
       JOIN v24.fibers f ON f.install_id = c.install_id
      WHERE f.disposed_at IS NULL)
  + (SELECT count(*) FROM v24.scopes s
      WHERE s.parent_id = p_scope_id AND s.closed_at IS NULL)
  + (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
       JOIN v24.effects e ON (e.request->>'install_id') = c.install_id::text
      WHERE e.kind IN ('host_prepare','host_release','inspect_resource')
        AND (e.status IN ('ready','claimed')
             OR (e.status = 'unknown' AND e.resource_quiesced_at IS NULL)))
$$;

-- 墓碑谓词（C27 六条）。p_exclude_effect 是被结算的那条 host_release（它此刻仍 claimed，
-- 必须排除，否则谓词恒 false；与 48:86 run_pin_release_set 的 p_effect_id 同法）。
CREATE FUNCTION v24.install_disposed_ok(p_install_id uuid, p_exclude_effect uuid DEFAULT NULL)
RETURNS boolean
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  SELECT
    NOT EXISTS (SELECT 1 FROM v24.fibers f
                 WHERE f.install_id = p_install_id AND f.disposed_at IS NULL)
    AND NOT EXISTS (SELECT 1 FROM v24.fibers f
                      JOIN v24.episodes e ON e.fiber_id = f.fiber_id
                     WHERE f.install_id = p_install_id AND e.state <> 'closed')
    AND NOT EXISTS (SELECT 1 FROM v24.fibers f
                      JOIN v24.slots s ON s.fiber_id = f.fiber_id
                     WHERE f.install_id = p_install_id AND s.released_at IS NULL)
    AND NOT EXISTS (SELECT 1 FROM v24.installs ci
                      JOIN v24.fibers f ON f.fiber_id = ci.owner_fiber_id
                                       AND f.install_id = p_install_id
                     WHERE ci.state <> 'disposed')
    AND NOT EXISTS (SELECT 1 FROM v24.effects e
                     WHERE (e.request->>'install_id') = p_install_id::text
                       AND (p_exclude_effect IS NULL OR e.effect_id <> p_exclude_effect)
                       AND e.kind IN ('host_prepare','host_release','inspect_resource')
                       AND (e.status IN ('ready','claimed')
                            OR (e.status = 'unknown' AND e.resource_quiesced_at IS NULL)))
    AND cardinality(v24.cleanup_cycle(p_install_id)) = 0
$$;

-- 发 release 前的谓词：C27 的前五条（第 5 条的「无 ready|claimed」由调用方另判），
-- 不含环以外的新条件。用于 dispose_stage 第 6 步，避免与「刚发的 release」自指。
CREATE FUNCTION v24.install_disposed_ok_except_release(p_install_id uuid)
RETURNS boolean LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  SELECT
    NOT EXISTS (SELECT 1 FROM v24.fibers f
                 WHERE f.install_id = p_install_id AND f.disposed_at IS NULL)
    AND NOT EXISTS (SELECT 1 FROM v24.fibers f
                      JOIN v24.episodes e ON e.fiber_id = f.fiber_id
                     WHERE f.install_id = p_install_id AND e.state <> 'closed')
    AND NOT EXISTS (SELECT 1 FROM v24.fibers f
                      JOIN v24.slots s ON s.fiber_id = f.fiber_id
                     WHERE f.install_id = p_install_id AND s.released_at IS NULL)
    AND NOT EXISTS (SELECT 1 FROM v24.installs ci
                      JOIN v24.fibers f ON f.fiber_id = ci.owner_fiber_id
                                       AND f.install_id = p_install_id
                     WHERE ci.state <> 'disposed')
    AND NOT EXISTS (SELECT 1 FROM v24.effects e
                     WHERE (e.request->>'install_id') = p_install_id::text
                       AND e.kind IN ('host_prepare','host_release','inspect_resource')
                       AND (e.status = 'unknown' AND e.resource_quiesced_at IS NULL))
    AND cardinality(v24.cleanup_cycle(p_install_id)) = 0
$$;

-- scope 终态谓词：{ok, blockers:{runs,installs,fibers,children,effects,cycles}}。
CREATE FUNCTION v24.scope_closable(p_scope_id uuid) RETURNS jsonb
LANGUAGE sql STABLE SET search_path = pg_catalog, v24 AS $$
  WITH b AS (
    SELECT
      (SELECT count(*) FROM v24.runs r
        WHERE r.scope_id = p_scope_id AND r.status NOT IN
              ('completed','failed','cancelled','blocked_unknown')) AS runs,
      (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
         JOIN v24.installs i ON i.install_id = c.install_id
        WHERE i.state <> 'disposed') AS installs,
      (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
         JOIN v24.fibers f ON f.install_id = c.install_id
        WHERE f.disposed_at IS NULL) AS fibers,
      (SELECT count(*) FROM v24.scopes s
        WHERE s.parent_id = p_scope_id AND s.closed_at IS NULL) AS children,
      (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
         JOIN v24.effects e ON (e.request->>'install_id') = c.install_id::text
        WHERE e.kind IN ('host_prepare','host_release','inspect_resource')
          AND (e.status IN ('ready','claimed')
               OR (e.status = 'unknown' AND e.resource_quiesced_at IS NULL))) AS effects,
      (SELECT count(*) FROM v24.cleanup_closure(p_scope_id) c
        WHERE cardinality(v24.cleanup_cycle(c.install_id)) > 0) AS cycles
  )
  SELECT jsonb_build_object(
    'ok', b.runs + b.installs + b.fibers + b.children + b.effects + b.cycles = 0,
    'blockers', to_jsonb(b))
    FROM b
$$;

-- 单个 fiber 的一个 deactivate 阶段。返回 {action, episode?, slot?, pins?, fiber, reason?}；
-- action ∈ {retire, blocked, release, close, idle}。
CREATE FUNCTION v24.deactivate_stage(p_fiber_id uuid, p_by_effect uuid)
RETURNS jsonb LANGUAGE plpgsql SET search_path = pg_catalog, v24 AS $$
DECLARE
  v_f v24.fibers%ROWTYPE; v_ep v24.episodes%ROWTYPE;
  v_slot uuid; v_barrier boolean; v_pins jsonb;
BEGIN
  SELECT * INTO v_f FROM v24.fibers WHERE fiber_id = p_fiber_id FOR UPDATE;
  IF NOT FOUND THEN RETURN jsonb_build_object('error', v24.error_v1('invalid_args')); END IF;
  IF v_f.current_episode_id IS NULL THEN
    RETURN jsonb_build_object('action','idle',
      'fiber',jsonb_build_object('key',jsonb_build_object('fiber_id',p_fiber_id),
        'set',jsonb_build_object('want_on',false)));
  END IF;
  SELECT * INTO v_ep FROM v24.episodes
   WHERE episode_id = v_f.current_episode_id FOR UPDATE;

  IF v_ep.state = 'active' THEN
    RETURN jsonb_build_object('action','retire',
      'episode',jsonb_build_object('key',jsonb_build_object('episode_id',v_ep.episode_id),
        'set',jsonb_build_object('state','retiring','retire_started_at',now())),
      'slots',(SELECT coalesce(jsonb_agg(jsonb_build_object(
                  'key',jsonb_build_object('slot_id',s.slot_id),
                  'set',jsonb_build_object('withdrawn_at',now()))),'[]'::jsonb)
                 FROM v24.slots s
                WHERE s.episode_id = v_ep.episode_id
                  AND s.withdrawn_at IS NULL AND s.released_at IS NULL),
      'fiber',jsonb_build_object('key',jsonb_build_object('fiber_id',p_fiber_id),
        'set',jsonb_build_object('want_on',false)));
  END IF;

  SELECT (EXISTS (SELECT 1 FROM v24.pins p
                   WHERE p.provider_episode_id = v_ep.episode_id AND p.released_at IS NULL)
       OR EXISTS (SELECT 1 FROM v24.installs ci
                   WHERE ci.owner_fiber_id = v_f.fiber_id
                     AND ci.owner_episode_id = v_ep.episode_id
                     AND ci.state <> 'disposed')
       OR EXISTS (SELECT 1 FROM v24.effects he
                   WHERE he.kind IN ('host_prepare','host_release')
                     AND (he.request->>'install_id') = v_f.install_id::text
                     AND (he.status IN ('ready','claimed')
                          OR (he.status = 'unknown' AND he.resource_quiesced_at IS NULL))))
    INTO v_barrier;
  IF v_barrier THEN
    RETURN jsonb_build_object('action','blocked','reason','barrier');
  END IF;

  SELECT coalesce(jsonb_agg(jsonb_build_object(
           'key',jsonb_build_object('pin_id',p.pin_id),
           'set',jsonb_build_object('released_at',now(),'released_by_effect',p_by_effect))),
         '[]'::jsonb)
    INTO v_pins
    FROM v24.pins p
   WHERE p.consumer_episode_id = v_ep.episode_id AND p.released_at IS NULL;

  SELECT s.slot_id INTO v_slot FROM v24.slots s
   WHERE s.episode_id = v_ep.episode_id AND s.released_at IS NULL
   ORDER BY s.contribution_seq DESC LIMIT 1;

  IF v_slot IS NOT NULL THEN
    RETURN jsonb_build_object('action','release','pins',v_pins,
      'slot',jsonb_build_object('key',jsonb_build_object('slot_id',v_slot),
        'set',jsonb_build_object('released_at',now())),
      'fiber',jsonb_build_object('key',jsonb_build_object('fiber_id',p_fiber_id),
        'set',jsonb_build_object('want_on',false)));
  END IF;

  RETURN jsonb_build_object('action','close','pins',v_pins,
    'episode',jsonb_build_object('key',jsonb_build_object('episode_id',v_ep.episode_id),
      'set',jsonb_build_object('state','closed','closed_at',now())),
    'fiber',jsonb_build_object('key',jsonb_build_object('fiber_id',p_fiber_id),
      'set',jsonb_build_object('want_on',false,'current_episode_id',NULL)));
END;
$$;

-- 单个 install 的一个 dispose 阶段。迭代工作队列，不是递归函数调用。
-- 返回 {action:'progress'|'blocked'|'release'|'terminal', installs[], fibers[],
--       episodes[], slots[], pins[], successors[], events[], reason}。
CREATE FUNCTION v24.dispose_stage(p_install_id uuid, p_by_effect uuid, p_mode text)
RETURNS jsonb LANGUAGE plpgsql SET search_path = pg_catalog, v24 AS $$
DECLARE
  v_queue uuid[] := ARRAY[p_install_id];
  v_cur uuid; v_i v24.installs%ROWTYPE; v_kid uuid; v_stage jsonb;
  v_rows int := 0; v_cycle uuid[]; v_rel uuid; v_target uuid; v_tstatus text;
  v_installs jsonb := '[]'::jsonb; v_fibers jsonb := '[]'::jsonb;
  v_eps jsonb := '[]'::jsonb; v_slots jsonb := '[]'::jsonb;
  v_pins jsonb := '[]'::jsonb; v_succ jsonb := '[]'::jsonb;
  v_events jsonb := '[]'::jsonb;
BEGIN
  IF p_mode NOT IN ('command','cascade','close') THEN
    RETURN jsonb_build_object('error', v24.error_v1('invalid_args'));
  END IF;
  WHILE cardinality(v_queue) > 0 AND v_rows < 16 LOOP
    v_cur := v_queue[1]; v_queue := v_queue[2:];
    SELECT * INTO v_i FROM v24.installs WHERE install_id = v_cur FOR UPDATE;
    IF NOT FOUND THEN
      RETURN jsonb_build_object('error', v24.error_v1('invalid_args'));
    END IF;
    IF v_i.state = 'disposed' THEN CONTINUE; END IF;

    v_cycle := v24.cleanup_cycle(v_cur);
    IF cardinality(v_cycle) > 0 THEN
      RETURN jsonb_build_object('error', v24.error_v1('cleanup_cycle',
        jsonb_build_object('path', to_jsonb(v_cycle), 'install_id', v_cur)));
    END IF;

    -- 0b. prepare/prepare_unknown：只发 inspect（保持原态），不进入 dispose_pending。
    IF v_i.state IN ('preparing','prepare_unknown') THEN
      SELECT e.effect_id, e.status INTO v_target, v_tstatus
        FROM v24.effects e
       WHERE (e.request->>'install_id') = v_cur::text
         AND e.kind = 'host_prepare'
       ORDER BY e.created_at DESC LIMIT 1;
      IF v_tstatus IN ('ready','claimed') THEN
        RETURN jsonb_build_object('action','blocked','reason','host_effect');
      END IF;
      IF v_target IS NOT NULL AND v_tstatus = 'unknown' THEN
        v_succ := v_succ || jsonb_build_array(jsonb_build_object(
          'effect_id', v24.inspect_effect_id(p_by_effect, v_cur),
          'ordinal',0,'kind','inspect_resource',
          'request',jsonb_build_object('v',1,'install_id',v_cur,'target','host_prepare',
            'target_effect_id',v_target,
            'reservation',(SELECT x.request->>'reservation' FROM v24.effects x
                            WHERE x.effect_id = v_target),
            'request_digest',(SELECT encode(x.request_digest,'hex') FROM v24.effects x
                               WHERE x.effect_id = v_target))));
        v_events := v_events || jsonb_build_array(jsonb_build_object(
          'entity_type','install','entity_id',v_cur,
          'event_kind','install_inspect_requested',
          'payload',jsonb_build_object('install_id',v_cur,'target_effect_id',v_target)));
        RETURN jsonb_build_object('action','progress','installs',v_installs,
          'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,'pins',v_pins,
          'successors',v_succ,'events',v_events);
      END IF;
      RETURN jsonb_build_object('action','blocked','reason','prepare_effect_missing');
    END IF;

    -- 1. 持久化 dispose 意图；把一个未 pending 的 child 入队（意图向下）。
    IF v_i.state <> 'dispose_pending' THEN
      v_installs := v_installs || jsonb_build_array(jsonb_build_object(
        'key',jsonb_build_object('install_id',v_cur),
        'set',jsonb_build_object('state','dispose_pending','dispose_effect',p_by_effect)));
      v_events := v_events || jsonb_build_array(jsonb_build_object(
        'entity_type','install','entity_id',v_cur,'event_kind','install_dispose_pending',
        'payload',jsonb_build_object('install_id',v_cur,'by',p_mode)));
      v_rows := v_rows + 1;
      SELECT ci.install_id INTO v_kid
        FROM v24.installs ci JOIN v24.fibers f
          ON f.fiber_id = ci.owner_fiber_id AND f.install_id = v_cur
       WHERE ci.state <> 'dispose_pending'
       ORDER BY ci.install_id LIMIT 1;
      IF v_kid IS NOT NULL THEN v_queue := v_queue || v_kid; END IF;
      CONTINUE;
    END IF;

    -- 2. 子先于 owner：把一个未 disposed 的 child 放到队首继续处理。
    SELECT ci.install_id INTO v_kid
      FROM v24.installs ci JOIN v24.fibers f
        ON f.fiber_id = ci.owner_fiber_id AND f.install_id = v_cur
     WHERE ci.state <> 'disposed'
     ORDER BY ci.install_id LIMIT 1;
    IF v_kid IS NOT NULL THEN
      v_queue := ARRAY[v_kid] || v_queue;
      CONTINUE;
    END IF;

    -- 3. unknown 未静默：只发 inspect，绝不发第二条 release。
    SELECT e.effect_id INTO v_target
      FROM v24.effects e
     WHERE (e.request->>'install_id') = v_cur::text
       AND e.kind IN ('host_prepare','host_release')
       AND e.status = 'unknown' AND e.resource_quiesced_at IS NULL
     ORDER BY e.created_at LIMIT 1;
    IF v_target IS NOT NULL THEN
      v_succ := v_succ || jsonb_build_array(jsonb_build_object(
        'effect_id', v24.inspect_effect_id(p_by_effect, v_cur),
        'ordinal', 0, 'kind', 'inspect_resource',
        'request', jsonb_build_object(
          'v',1,'install_id',v_cur,'target',
            (SELECT x.kind FROM v24.effects x WHERE x.effect_id = v_target),
          'target_effect_id',v_target,
          'reservation',(SELECT x.request->>'reservation' FROM v24.effects x
                          WHERE x.effect_id = v_target),
          'request_digest',(SELECT encode(x.request_digest,'hex') FROM v24.effects x
                             WHERE x.effect_id = v_target))));
      v_events := v_events || jsonb_build_array(jsonb_build_object(
        'entity_type','install','entity_id',v_cur,
        'event_kind','install_inspect_requested',
        'payload',jsonb_build_object('install_id',v_cur,'target_effect_id',v_target)));
      v_rows := v_rows + 1;
      RETURN jsonb_build_object('action','progress','installs',v_installs,
        'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,'pins',v_pins,
        'successors',v_succ,'events',v_events);
    END IF;

    -- 4. 仍有 ready/claimed host effect：本 advance 不推进。
    IF EXISTS (SELECT 1 FROM v24.effects e
                WHERE (e.request->>'install_id') = v_cur::text
                  AND e.kind IN ('host_prepare','host_release','inspect_resource')
                  AND e.status IN ('ready','claimed')) THEN
      RETURN jsonb_build_object('action','blocked','reason','host_effect',
        'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
        'pins',v_pins,'successors',v_succ,'events',v_events);
    END IF;

    -- 5. 本 install 的 fiber 仍需 retire/release/close：一次只推进一个 fiber。
    SELECT f.fiber_id INTO v_kid FROM v24.fibers f
     WHERE f.install_id = v_cur AND f.disposed_at IS NULL
     ORDER BY f.fiber_id LIMIT 1;
    IF v_kid IS NOT NULL THEN
      v_stage := v24.deactivate_stage(v_kid, p_by_effect);
      IF v_stage ? 'episode' THEN
        v_eps := v_eps || jsonb_build_array(v_stage->'episode');
      END IF;
      IF v_stage ? 'slot' THEN
        v_slots := v_slots || jsonb_build_array(v_stage->'slot');
      END IF;
      IF v_stage ? 'pins' THEN
        v_pins := v_pins || (v_stage->'pins');
      END IF;
      IF v_stage->'fiber' IS NOT NULL THEN
        -- close/idle 且已无 open episode：同一条 fiber update 里写墓碑。
        IF v_stage->>'action' IN ('close','idle')
           AND NOT EXISTS (SELECT 1 FROM v24.episodes e
                            WHERE e.fiber_id = v_kid AND e.state <> 'closed') THEN
          v_stage := jsonb_set(v_stage,'{fiber,set,disposed_at}',to_jsonb(now()));
        END IF;
        v_fibers := v_fibers || jsonb_build_array(v_stage->'fiber');
      END IF;
      v_rows := v_rows + 1
        + (CASE WHEN v_stage ? 'episode' THEN 1 ELSE 0 END)
        + (CASE WHEN v_stage ? 'slot' THEN 1 ELSE 0 END)
        + coalesce(jsonb_array_length(v_stage->'pins'),0);
      IF v_stage->>'action' IN ('retire','blocked','release') THEN
        RETURN jsonb_build_object('action','progress','stage',v_stage->>'action',
          'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
          'pins',v_pins,'successors',v_succ,'events',v_events);
      END IF;
      CONTINUE;  -- action='close'/'idle'：继续检查其它 fiber/义务
    END IF;

    -- 6. 全义务满足：发一条 release（已有 ready|claimed 复用；本步已排除）。
    IF NOT v24.install_disposed_ok_except_release(v_cur) THEN
      RETURN jsonb_build_object('action','blocked','reason','obligation',
        'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
        'pins',v_pins,'successors',v_succ,'events',v_events);
    END IF;
    IF NOT EXISTS (SELECT 1 FROM v24.effects e
                    WHERE (e.request->>'install_id') = v_cur::text
                      AND e.kind = 'host_prepare' AND e.status = 'succeeded') THEN
      v_installs := v_installs || jsonb_build_array(jsonb_build_object(
        'key',jsonb_build_object('install_id',v_cur),
        'set',jsonb_build_object('state','disposed','disposed_at',now())));
      v_events := v_events || jsonb_build_array(jsonb_build_object(
        'entity_type','install','entity_id',v_cur,'event_kind','install_disposed',
        'payload',jsonb_build_object('install_id',v_cur,'released',false)));
      RETURN jsonb_build_object('action','progress','direct_disposed',v_cur,
        'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
        'pins',v_pins,'successors',v_succ,'events',v_events);
    END IF;
    v_rel := md5(p_by_effect::text || ':host_release:' || v_cur::text || ':0')::uuid;
    v_succ := v_succ || jsonb_build_array(jsonb_build_object(
      'effect_id',v_rel,'ordinal',0,'kind','host_release',
      'request',jsonb_build_object('install_id',v_cur,
        'reservation','v24:host_release:' || v_rel::text)));
    v_events := v_events || jsonb_build_array(jsonb_build_object(
      'entity_type','install','entity_id',v_cur,
      'event_kind','install_release_requested',
      'payload',jsonb_build_object('install_id',v_cur,'release_effect_id',v_rel)));
    RETURN jsonb_build_object('action','release','release_install_id',v_cur,
      'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
      'pins',v_pins,'successors',v_succ,'events',v_events);
  END LOOP;
  RETURN jsonb_build_object('action','blocked','reason','budget',
    'installs',v_installs,'fibers',v_fibers,'episodes',v_eps,'slots',v_slots,
    'pins',v_pins,'successors',v_succ,'events',v_events);
END;
$$;
```

`install_disposed_ok_except_release(uuid)`（**NEW**）= `install_disposed_ok` 的前五条（不含「无 ready|claimed host effect」与环），因为第 6 步要发的那条 release 尚未存在；它仍要求 fibers/episodes/slots/child/unknown 全清。这样墓碑谓词与「发 release 前」谓词分开，避免自指。
