## Frozen fields

### `NodeKind` (closed set)

```text

```

Python enum names: `DOCUMENT`, `SECTION`, `PARAGRAPH`, `SENTENCE`, `ATTACHMENT`.

### Payload / node records

`DocumentPayload` (`types.py:36-44`): `document_id`, `title`, `text`, `metadata`, optional `sections`.

`SectionPayload`: `title`, `paragraphs`, `metadata`.

`ParagraphPayload`: `text`, optional `sentences`, `metadata`.

`SentencePayload`: `text`, `metadata`.

`TreeNode` (`types.py:47-58`): `node_id`, `kind`, `text`, `title`, `metadata`, `parent_id`, `children`, optional `embedding`.

`StoredNode` (`types.py:62-72`): persisted form with required `embedding` and `child_ids`.

### Tree construction (indexer)

`indexer.py:82-178`:

- Root: `kind=document`, `node_id=document.document_id`.
- Section: `{document_id}:sec{n}` (1-based counter).
- Paragraph: `{section_id}:p{n}`.
- Sentence: `{paragraph_id}:s{n}`.
- Parent links: document → section → paragraph → sentence.
- Section/paragraph/sentence metadata always receive `document_id` and `document_title`.

**`ATTACHMENT` is declared but not created by `indexer.py`.** The only other `NodeKind.ATTACHMENT` hit is `scripts/wattbot_stats.py:54`. PDF images are **paragraphs** with `metadata.attachment_type="image"` (`pdf_utils.py:123-145`), not `NodeKind.ATTACHMENT` nodes.

### PDF page numbering in KohakuRAG

`pdf_utils.py:93`: `enumerate(reader.pages, start=1)` — KohakuRAG PDF pages are **1-based** in paragraph/section metadata `page`. Image keys: `img:{doc_id}:p{page}:i{idx}` with page and index 1-based (`datastore.py:990-1001`).

This is **not** MinerU `page_idx` (0-based).

### Parsers

- `text_to_payload`: heuristic paragraphs/sentences; one autogenerated section (`parsers.py:22-53`).
- `markdown_to_payload`: ATX headings `#{1,6}` become sections; heading metadata `level` = count of `#` (`parsers.py:56-149`).
- `dict_to_payload` / `payload_to_dict`: JSON round-trip of the payload dataclasses (`parsers.py:152-197`).
