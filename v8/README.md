# pg-agent v8 · Postgres-Native Agent（P0A 核心 + P0B 最小闭环）

一句话定位：按冻结合同 `docs/designs/v8-dev.md`（2026-09-14 T56 终审冻结）实现的 Postgres-native agent 运行时。Postgres 拥有持久化状态机、合法状态转移与 effect 决策；worker 只执行已持久化的 effect，外部 IO 一律不进事务。

**本轮交付范围**：P0A 的核心冻结件（canonical profile、事件 ABI、receipt/binding、双 fence、状态机核心 DDL）+ P0B 最小闭环（`user event → create step（与初始 decision seal 同事务）→ fake LLM effect → dispatch → complete → assistant event → turn 关闭 → finish_session`，含 kill-at-every-boundary chaos 验收）+ native 生命周期 G6（tools seal 第二条 seal 路径与工具批次：`决策返回 tool calls → step ready/decision → seal_batch → tool 批次 dispatch/complete → final_tools 全成功终态化 → 下一 decision step → decision_only 关 turn → finish`）+ G7a–G7c（known_failure 结算与 retry cohort 分配、recovery 接管、repair + turn-end closer 槽位链）+ G8a（request_cancel 粘性停止收束：三窗口收束、pre-dispatch 双表同步、turn/end 派生、与 finish/dispatch 两序竞态）+ G8b（共享取消收束子操作五出口与 AG01 触发源收口、聚合规则 3 补全与 cancel-wins 矩阵、effect 级取消 code 闭合映射、Conformance 6/15）+ G13（P0C dsh-compat **host 无关合同面**：`compat_unmapped_audit` 统一命令、adapter manifest 落库、P0C passed/failed/blocked 报告器、§5.1 十六行映射数据库层、fake 必跑与显式 optional smoke、schema v2 五状态及三结论报告）。P0C 的真实 I/O 半边（pinned Node host、§5.2 前置验证、全部真实 I/O 层子用例）仍未交付；插件世代、授权/安全数据库机制等已由 G10–G19 交付，剩余 runtime/compat 执行面及规格 [LATER] 合同按下文分层列示——范围对照见 `docs/analysis/v8-impl-digest/*.md` 的 [P0B-CORE]/[LATER] 标注与 `v8/compat/pinned_host_manifest.json` 的 blocked 清单。

## Stage 与 gate（里程碑准出必须全绿）

**J0 keyless 基线（2026-09-17）**：同一 fresh run 24/24 脚本 exit 0、源快照无漂移；G13 181 条 `[PASS]` 输出行（仅观测，不是独立断言数），真实 provider 未调用。机器清单为 `v8/regression/v8-gates.json`，完整版本/hash/各 gate 计数见 `docs/reviews/v8-j0-keyless-baseline-2026-09-17.md`。runner 可在单项失败后继续收集本轮诊断，但不得据此进入下一里程碑或提交完成。
